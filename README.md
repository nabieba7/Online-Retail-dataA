# Online-Retail-dataA
Online Retail Sales Analysis
Data cleaning, exploratory analysis and an interactive dashboard for the UCI Online Retail dataset (UK online retailer, Dec 2010 to Dec 2011).
Files
online_retail_analysis.ipynb: the full analysis and dashboard
Online-Retail.xlsx: not included in this repository 
How to run
Download the workbook from Moodle and save it as Online-Retail.xlsx in the same folder as the notebook.
Install the packages:
pip install pandas matplotlib plotly ipywidgets openpyxl nbformat
Open the notebook in Jupyter or VS Code and choose Kernel > Restart and Run All.
The dashboard at the end of the notebook has a country dropdown, a date range and a UK checkbox. Interactive widgets need Jupyter or VS Code, not a static HTML or PDF export.
